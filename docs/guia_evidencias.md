# Capturas de tela para a entrega

Este guia foi preparado para facilitar a correção **sem exigir que o professor execute o repositório**.

## Como registrar as imagens

1. Abra o terminal do VS Code na pasta do projeto.
2. Execute `python verificar_entrega.py` e confira o resultado **8/8**.
3. Execute `python -m unittest discover -s tests -v` e confira `OK`.
4. Execute `python -m streamlit run app.py` e abra `http://localhost:8501`.
5. Utilize **Win + Shift + S** para capturar as telas reais, preservando os títulos e os resultados legíveis.

## Anexando ao projeto e à entrega

Você pode criar `docs/evidencias/` para guardar as imagens, se desejar documentá-las também no GitHub. **Se o professor pediu arquivos de imagem enviados diretamente na plataforma da faculdade, anexe-os lá também**; o link do GitHub sozinho não substitui esse requisito.

Crie uma pasta com as capturas e coloque a identificação da disciplina e o link público do repositório na descrição da entrega. Confira o prazo final de **29/10/2026, às 19h BRT**.
